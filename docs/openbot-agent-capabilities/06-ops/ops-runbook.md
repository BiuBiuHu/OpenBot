# OpenBot 智能体能力 · 运维手册

## 0. 版本历史

| 版本 | 日期 | 变更内容 | 变更原因 | 影响 |
|------|------|----------|----------|------|
| v0.1 | 2026-10-01 | 首版。本机进程运维，无云发布 | 用户禁止部署；产品跑在笔记本环回 | 巡检只针对本机 `openbot serve` 与公开 HTTP 抓取 |

## 1. 当前决策

- 当前运维目标：保证本机页能发送聊天、文档路径能出网读公开页；不运营共享集群。
- 当前巡检方式：本机健康（进程在、环回端口开、可选 `GET` 公开 raw）。
- 当前故障处理边界：修本机分流与网络；不登录用户 ECS 代运维（用户曾禁止 SSH 到 ECS 做交付）。不打印密钥。

## 2. 环境和配置

- 本地：`npx tsx src/cli.ts serve`，页面 `http://127.0.0.1:<port>/`。
- 预发：无。
- 生产：无。
- 关键环境变量：语言与 SSH **路径**在 `~/.openbot/config.json`；session key 只在本机 `~/.openbot/.env`。文档路径不新增变量。
- 数据库/schema：无。
- 下游服务：公开 HTTP；交接才用隧道后的 OpenHands。VNC 只环回。

## 3. 发布门禁

- 发布方案评审：`06-ops/release-plan.md` 为 `rejected`（禁止部署）。

- 发布完成条件：不得宣布生产发布完成。

## 4. 日常巡检

### 4.1 启动检查

```bash
npx tsx src/cli.ts serve
# 浏览器只打开 127.0.0.1，不要把公网地址写进记录
```

### 4.2 健康检查

- 页能打开、Settings 语言仍在。
- 发送文档问句得到「我看过了」或「这个链接我没读成」，不是超时套话。
- 不要在巡检记录里写 PEM、session key、ECS 公网 IP。

### 4.3 数据和对象存储检查

无。评测文件若存在，应在 `~/.openbot/evals/` 且模式 0600。

## 5. 告警和故障处理

### 5.1 告警等级

无云告警。本机：文档路径失败=P3（读不成）；再次出现超时套话当文档答=P0。

### 5.2 常见故障归因

| 现象 | 先查 | 不要先做 |
|------|------|----------|
| 又回超时套话 | `runThreadTurn` 是否还走 document | 去改 ECS |
| 读不成 | URL 是否公开、是否 blob 未改 raw、本机出网 | 要 GitHub token |
| OH 说明书 | 是否误入 handoff | 改文案掩饰 |

### 5.3 证据保留

shown 文本与 conversation id 可进 `~/.openbot/evals/live.jsonl`。禁止主机地址与密钥。
