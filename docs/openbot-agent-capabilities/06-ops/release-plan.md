## 2. 调用链与关联系统盘点

沿真实调用链：笔记本页 → 本机 `openbot serve` → 公开 HTTP；交接时才经 SSH 隧道到用户自有 ECS。无 Auth 服务、无邮件、无 Worker 发布、无对象存储、无运营后台。

- Runtime entry inventory 路径/版本：无独立清单。入口事实：本机环回页。禁止把公网 alias 写进本文件。
- 本次登录入口：无账号体系。
- 本次主服务/BFF URL：仅 `http://127.0.0.1:<port>/`。
- 本次 provider callback URL：无。
- 本次业务回跳 URL：无。
- callback/fixed alias inspect 结果：不适用。
