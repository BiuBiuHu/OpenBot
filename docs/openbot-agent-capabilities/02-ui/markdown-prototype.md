# OpenBot 智能体能力 · Markdown UI 原型

## 0. 版本历史

| 版本 | 日期 | 变更内容 | 变更原因 | 影响 |
|------|------|----------|----------|------|
| v0.1 | 2026-10-01 | 首版。本增量不改页面结构，只约定文档短答出现在原线程 | 文档能力走同一输入框；禁止新 mode | 不新增路由、页签、上传控件 |

## 1. 当前决策

- 当前 UI 结构：左聊天 + 右 16:10 电脑卡片。本增量不改布局。
- 当前交互风格：一个人话气泡。文档成功以「我看过了。」开头；失败「这个链接我没读成。」
- 当前平台形态：本机 Web（`openbot serve` 环回）。
- 页面类型：C 端工具页，不是 B 类运营台。
- 效率目标：人不用离开输入框，不用切换「文档模式」。

B 类运营效率检查、批量工具条、详情抽屉：**不适用**。本产品无运营后台。开源后台表格调研不纳入本页。

## 2. 入口与信息架构

### 2.1 页面入口

笔记本浏览器打开本机 `http://127.0.0.1:<当次端口>/`。Settings 仍在同一页。

### 2.2 导航层级

无多页。无「文档」页签。

### 2.3 信息分组

- 聊天抄本：人话与短答。
- 电脑卡片：ECS 帧缓冲（本增量只要求不回退）。
- Settings：语言、SSH 路径。不展示私钥正文。

### 2.4 上下文与冗余控制

- 哪些信息由筛选区/页面标题表达，不在每行重复：不适用（无表）。
- 哪些字段必须在列表中直接可见：不适用。
- 哪些长内容只进入详情抽屉：公开文档全文**不**糊进聊天；只出标题和两句。

## 3. 页面清单

| 页面/弹窗 | 入口 | 目标用户 | 关键动作 | 权限 |
|-----------|------|----------|----------|------|
| 主聊天 | `/` | 使用者 | 发送文档问句 | 本机 |
| Settings | 同页 | 使用者 | 设语言 | 本机 |
| 电脑卡片放大 | 双击 / 放大 | 使用者 | 看桌面 | 本机；本增量不改 |

## 4. 关键页面原型

### 4.1 主聊天（无新控件）

```
+--------------------------------------------------+
| OpenBot                    [设置 语言=简体中文]   |
| +----------------------+  +--------------------+ |
| | 人: 看看 https://…   |  |   16:10 桌面卡片   | |
| |     这个文档讲了什么? |  |   (帧缓冲 only)    | |
| |                      |  |                    | |
| | 机: 我看过了。这一章 |  |                    | |
| |     是「用户记忆和   |  |                    | |
| |     知识库」。…      |  |                    | |
| +----------------------+  +--------------------+ |
| | [输入框                        ] [发送]       | |
+--------------------------------------------------+
```

- 布局：维持 `src/ui/index.html`。
- 字段：唯一 `#box`。
- 操作：回车/发送 → `POST /api/chat`。
- 列表列：不适用。
- 行内可视对象：不适用。
- 详情信息：无抽屉。
- 批量操作：无。
- 反馈：thinking 状态后出 token。禁止出现「conversation timed out」原文。

### 4.2 外部参考取舍

- 候选：Claude 抓页后长文引用、OpenHands 浏览器窗口。
- 采纳：指定 URL 才读；聊天里只给人话。
- 拒绝：文档 mode、引用卡片墙、在聊天里嵌 noVNC 去「打开那篇」。
- 本地化：简体短句，不用英文源段。

## 5. 状态与交互

### 5.1 加载、空态、错误态

- 加载：原 thinking。
- 读不成：一句失败人话。
- 真电脑超时（非文档路径）：原超时句。

### 5.2 表单校验和保存反馈

Settings 语言保存仍走既有配置。文档路径无表单。

### 5.3 权限差异和只读状态

无。

### 5.4 预发/线上环境标识

无共享环境。环回即工作环境。

### 5.5 B 类运营效率检查

不适用。理由：没有集合总览、没有审核对象、没有批量生图。

## 6. 响应式与终端范围

桌面浏览器。电脑卡片已有放大/收起/Escape。本增量不改视口策略。

## 7. 未解决问题

- 工作区文稿若以后要在 UI 露出文件名，再改本原型，仍不得新开 mode。
