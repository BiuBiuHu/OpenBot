## 2. 环节核心内容

### 2.1 客户端范围判定

涉及本机 Web 聊天。无移动端、无小程序。桌面卡片本增量不改。

### 2.2 能力矩阵

| 客户端 | 运行 | 环境 | 路径 | 依赖 | 结果 |
|--------|------|------|------|------|------|
| 本机 Web | tsx / node:test | 环回 | 文档问句 | 主服务 fetch | 待回填 |

### 2.3 联调门禁

- 进程和端口拓扑：测试自管；文档路径不启 OH mock 会话。
- 环境变量：`OPENBOT_HOME` 临时目录。
- 预发运行时健康：不适用。
- 客户端网关边界：无内部 URL 进 `src/ui`。
- 数据库和迁移：不适用。
- service-to-service：主服务 → 公开 HTTP。禁止主服务 → OH（文档句）。
- 第三方 API：可选 raw GitHub。
- Web smoke：无 UI 改动；以 API/单测代替截图。
- 认证专项：不适用。
- 失败归因：分流 / 网络 / 抽取。
