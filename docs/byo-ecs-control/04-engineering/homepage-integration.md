# 首页远端电脑操作整合

2026-11-20，沿用用户授权：在当前首页顺畅操作远端电脑，补齐任务、审批、恢复，不修改安派仓库。
保存点：2835d47 + /tmp/openbot-before-home-integration.patch；首页原稿 /tmp/openbot-index-before-integration.html。

## 决策与变更

- 首页发送统一调用独立 Bot 的版本化任务 API，由 ECS 上的 Agent 理解并执行自然语言；不再让本地 Pi/A2A 的一次请求生命周期承担首页远端任务。
- 原 /api/chat 保留兼容，独立 /bot 保留诊断入口；首页不再依赖它们完成操作。
- src/ui/home-bot.js 管理任务记录、原始动作审批、暂停/继续、文件列表与预览；原桌面面板保留。
- 首页与 /bot 使用同一私有代理/session 边界；原始远端服务 token 不传入页面。
- 本机只保存 threadId 与未确认提交的 requestId/goal。执行结果从 ECS 恢复；轮询期间不重建已有卡片，避免审批/阅读被刷新打断。
- 本地服务重启后从同源首页更新 page session，再验证远端实例，自动恢复任务查询。写入和审批不自动重试；未知提交保持原 requestId，由原任务列表核对或用户明确重试。
- 全部任务分页读取；待确认任务/暂停任务仍阻塞远端串行队列。暂停不等于终止底层子进程。

## 验收范围

首页发送 -> ECS 接收 -> 展示原始动作 -> 页面审批 -> 执行中本机关闭 -> 自动重连 -> 原任务恢复 -> 读取结果与文件。刷新待审批状态、文件路径错误与鉴权为相邻回归。

## 边界

这是单用户可信 ECS，终端并非严格沙箱。自然语言任务是独立目标，尚未实现跨任务的长期语义记忆。桌面显示/手动交互保留，不因此宣称任意网页自动化已验收。机器重启、数小时压力、生产服务安装另行验收。
