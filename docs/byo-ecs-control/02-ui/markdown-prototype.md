# 独立 Bot 测试入口

## 0. 版本历史
v0.1 / 2026-11-20：新增 `/bot`，验证插件接口，不修改安派。

## 1. 当前决策
工具页，延续原生 HTML，无新增 UI 框架。左侧提交自然语言任务与任务列表；右侧连接和文件查看。原聊天仍可使用。

## 2. 入口与信息架构
原首页链接进入 `/bot`，页面可返回 SSH 设置。连接主机名统一来自配置。每条任务显示目标、真实状态、短 ID、结果及可执行动作；详情包含真实待执行工具参数。

## 3. 页面清单
连接表单（令牌、端口）、任务提交、任务列表、工作区浏览/预览。无批量操作。

## 4. 关键页面原型
提交后立即展示接收 ID；允许关闭页面。审批允许/拒绝、执行中暂停、暂停后恢复；不确定状态先核对。文件显示路径、内容和摘要。

## 5. 状态与交互
空态提示提交；无连接阻止提交；断线保留已有结果并说明任务状态未知。提交请求保留 requestId，响应丢失后同 ID 重试。刷新仅 GET，不新建任务。旧身份不符拒绝连接。所有结果使用 textContent 渲染。

## 6. 响应式与终端范围
桌面双列，窄屏单列；当前浏览器本机入口，移动端不直接连接 SSH。

## 7. 未解决问题
产物下载、长会话对话记忆、自动计划、多用户、定时触发不在当前垂直链路。安派集成仅调用 API，不引入本仓库代码或依赖。
