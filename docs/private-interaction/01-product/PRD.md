# 私密输入与用户接管

延续独立 ECS Personal Agent 功能；不修改安派仓库。默认自主执行，只有缺少用户私密输入、需要真人验证或确实无法继续时才请求用户协助。

## 核心闭环

用户提交网页任务 → Agent 操作网页 → 通过通用工具请求私密字段/接管 → 任务进入等待用户状态、页面明显提醒 → 用户在独立输入框填写或操作远程桌面 → 服务端执行代填/确认接管完成 → 原任务继续 → 返回有依据的结果。

私密输入不是聊天消息。浏览器端封装加密信封，绑定任务、请求、目标页面 origin、期限和一次性标识；ECS 服务端解密后直接代填。代理请求、持久化任务、Agent 事件、工具参数/返回和测试证据不包含明文。用户输入后立即清空本地表单，不写 localStorage。验证码按私密输入处理，扫码/人机验证交给用户。

“无法继续”通过通用接管工具表达原因与所需帮助；运行时另有基于停滞时间/工具失败的通用兜底，不写 163 专用判断规则。等待期间暂停 Agent 的后续动作；用户点击继续前不自动抢回控制。

## 首个验收场景

163 网页邮箱登录，读取并总结任务开始时向前 24 小时内的邮件（Asia/Shanghai 展示时间）。账号密码仅通过新输入框提供，禁止复用聊天里的旧明文。只读收件箱，不发送、删除、移动邮件或标记为已读（网页服务自身的已读行为需要准确记录）。若遇验证码/扫码，提示用户接管。摘要包括时间范围、邮件数量、主要内容、待办、未读取范围；不得将部分页面读取声称为全部邮件。

产品验收分成基础设施自测和真实账号验收：先用隔离站点证明不泄露、恢复和接管闭环；真实 163 需要用户通过表单输入并完成可能的验证，不把这些用户步骤当作已通过。
