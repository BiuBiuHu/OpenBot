# 自审

- 独立 Bot 实现；没有安派仓库或新增第三方包依赖。
- 私密字段走独立认证 API，代理只透传密文；MCP 能力令牌不能调用任务/信封 API。
- 私钥与脱敏值仅在服务端内存，日志/错误不打印输入、密文解密结果或浏览器异常原文。
- 信封绑定任务、请求、origin、期限；代填前消费，拒绝重放。
- 模型没有原始 JS/CDP、Cookie/Storage、截图或终端能力；显式限制内网浏览，保留测试 origin 配置。
- 输入请求与观察器并发时重新读取当前记录，避免丢失等待用户状态；用户返回继续原 conversation。
- 接管捕获私密输入只发生在用户控制阶段；恢复后停止捕获，已知值继续用于输出脱敏。
- 部署来自已提交最小构建；保留用户未提交的其它模块修改。
- 证据仅包含假凭据泄漏布尔检查和空的真实登录输入框，不包含真实凭据或真实邮件。
- 真实163尚待用户填写；没有用接口200替代业务验收。系统级root隔离与跨服务重启私密会话恢复为明确限制。

## 填写卡片 UI 自审

- 修复：原生裸输入框、密码显示按钮与输入分离、手动接管抢占主按钮位置、缺少加载态、错误提示不区分是否已经提交。
- src/ui/private-input.js：语义化 label/input/button、字段错误关联、首错聚焦、键盘提交、可访问的密码显示按钮、状态播报与可见焦点已验证。
- 样式仅作用于 .human-interaction；不添加包或影响安派/远端执行代码。
- 加密仍由独立字段策略决定，显示密码不改变提交方式；失败与完成后清空密码。加载期间阻止重复操作，交付不确定时不自动重放。
- 桌面/窄屏截图已检查，尊重 reduced-motion；截图仅含空表单。
