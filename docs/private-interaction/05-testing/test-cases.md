# 验收用例

1. 通用私密表单：账号/密码加密上传，服务端填入正确字段，模型调用和返回不出现两项值。
2. 协议失败：篡改密文、不同任务、过期、页面 origin 变化、重放均无代填副作用。
3. 页面回显：输入值在 DOM、正文、URL、错误中回显仍被屏蔽；不提供敏感截图或任意读取接口。
4. 持久化：任务、日志、浏览器本地 storage、证据中搜索随机 canary；无明文。重启后不丢失等待状态、不自动重放凭证。
5. 通用接管：Agent 请求用户协助，UI 明显提醒，等待期间无后续动作；用户完成后原任务继续。
6. 停滞：重复工具失败/无进展触发接管，不持续无意义重试；正常长任务不误判为完成。
7. 163 真实验收：用户在新表单输入，完成可能的人机验证；摘要覆盖已确认的最近 24 小时邮件，并明确缺失范围。未取得用户输入或无法访问时记为待验收，禁止伪造通过。
8. 回归：普通 ECS 文件与长期任务仍可自主执行，队列重启顺序、暂停和防重放不退化。
