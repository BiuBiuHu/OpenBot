# 设计与边界

保存点 f2305c7；已有用户工作区改动备份 /tmp/openbot-before-private-input.patch。沿用本次独立 Bot 功能分支，安派只作为未来 API 消费方。

## 能力边界

私密网页任务使用独立执行 profile，通过 OpenHands 原生 MCP 扩展接入受控浏览器工具与人类协助工具，不向该 profile 暴露 terminal、file_editor、任意 JavaScript、原始 CDP、Cookie 或存储读取。保留原普通 ECS 任务能力。不能靠提示词或少量密码关键词实现保密。

浏览器驱动在服务端操作可见 Chromium。模型仅得到清洗后的页面文本与元素标识；不返回表单值，不开放包含私密字段的截图。私密值仅供 broker 代填和输出脱敏，密文与秘密不进入模型上下文。账号可能在登录后页面被再次展示，因此输出清洗必须覆盖页面正文、URL、属性和错误；重启丢失脱敏上下文时，禁止自动恢复私密页面观察。

模型没有读取 broker 密钥的工具，但当前 ECS 的普通执行器为 root，不能把此应用层隔离宣传为抵抗恶意同机 root 进程的安全边界。生产硬隔离需要独立用户/容器、浏览器 profile 和受控网络命名空间。真实秘密不落模型可读工作区。

## 信封

WebCrypto AES-256-GCM 加密内容、RSA-OAEP/SHA-256 封装数据密钥；authenticated data 绑定 taskId/requestId/origin/expiry。服务端私钥不进入前端或 Agent。一次性请求在代填前记录已消费；响应丢失后只核对状态，不重放代填。过期、目标页变化、篡改、跨任务、重复信封全部拒绝。错误仅返回稳定错误码。

## 接管

任务保留结构化 interaction（原因、状态、目标、字段定义、期限），不存私密值。请求工具返回不含秘密的状态。待用户完成时禁止继续工具操作。继续原 conversation，不能另建任务或把填写值拼入 resume 消息。UI 显示明显接管卡片，标签页提醒；后台权限通知可选，不能替代页面可见状态。

## 已实现的运行边界

普通电脑任务也获得通用 `request_user_takeover` 工具；只有 `private_browser` profile 获得私密输入和受控网页工具。网页浏览默认拒绝内网/回环地址，防止通过调试器页面绕过工具边界；测试服务单独配置 `BOT_PRIVATE_BROWSER_ALLOWED_ORIGINS=http://127.0.0.1:3862`，不得照搬到生产。

手动接管期间通过隔离 JavaScript world 的 CDP binding 将输入值交给服务端内存脱敏器，绝不转发到 Agent。恢复前完成同步，再关闭手动输入捕获；模型普通搜索输入不会被当作私密输入。私密表单提交始终直接登记待脱敏值。结构化接管和表单状态保存在任务记录中，真实字段值不保存。

私密会话采用独立临时浏览器 context。关闭本地网页不关闭 ECS 会话；但 ECS 执行服务重启后不尝试恢复已失去脱敏上下文的会话，而将未完成私密任务标记中断，要求重新发起。当前不承诺私密登录态跨执行服务重启保留。

## 字段显示与加密更新（2026-11-20）

按用户最新要求，账号等普通字段可指定 `sensitive:false`，显示为文本输入并通过 `publicValues` 明文提交；密码及其它私密字段默认 `sensitive:true`，仍在 AES-GCM 密文中。实际远端 password 输入框强制私密，模型不能将其降级。普通字段作为 GCM 附加认证数据绑定信封，防止复用密码密文时替换账号。旧字段未指定策略时继续默认加密。

密码框提供显示/隐藏按钮，仅影响本地显示，不影响加密策略。提交成功或失败后清空输入并恢复隐藏；不读取真实密码做 UI 自测。沿用 SSH/HTTPS 传输，不因普通字段明文取消连接保护。
