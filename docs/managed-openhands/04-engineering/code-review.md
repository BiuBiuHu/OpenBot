# 自动安装器自审

日期：2026-11-20。范围：OpenBot 安装器、设置页、CLI、依赖锁；安派不涉及。

- 使用 SSH 参数数组和 shellQuote 传递固定安装器；依赖锁经 stdin 传递。密码与会话凭据不进入浏览器安装状态和错误消息。
- 安装 API 复用本地 session / Host / Origin 边界；未保存主机返回 400；同一主机并发请求复用安装 Promise，远端 flock 防止跨进程重入。
- 四个核心包固定 1.49.2，传递依赖取已有验证环境，下载哈希必须匹配；客户端核对远端返回的锁摘要。
- 安装失败不更新连接配置；候选健康失败恢复旧服务。已有其他 OpenHands 与 Bot Runtime 不接管、不重启。
- 独立服务账户，回环监听；会话环境文件 0600，本机凭据仅保存在 0600 环境文件。
- 观察限制：安装 API 状态在本机内存中，本机服务重启后状态不保留；可以重新检查，远端锁避免重复安装。未来升级时需要配套任务排空策略；本次只提供固定版本安装和幂等重入。
- 首版只支持 Ubuntu 24.04 x86_64。浏览器、模型与 Bot Runtime 尚非全自动部署，README/页面均说明“引擎就绪”的范围。
