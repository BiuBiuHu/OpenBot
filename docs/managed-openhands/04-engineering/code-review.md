# 完整初始化自审

日期：2026-11-21。范围：独立 OpenBot 的安装器、设置页、CLI、依赖锁、桌面与 Runtime；不涉及安派仓库。

- SSH 参数数组传递命令；模型密钥、锁文件和 Runtime 包经 stdin 传递，不进入命令参数。安装状态不返回令牌或模型密钥。
- 本地初始化 API 复用 session / Host / Origin 校验；远端 flock 防止并发写入，切换主机后不覆盖另一主机配置。
- OpenHands 1.49.2 和传递依赖带哈希锁；Node、Chromium 固定版本与 SHA-256。Runtime 仅打包已提交源码，同一提交复用归档。
- 服务以独立非 root 用户运行，监听回环地址，通过 SSH 隧道访问；模型配置和令牌权限 0600。Chromium 保留 sandbox，Ubuntu AppArmor 只对固定浏览器路径补充 userns 权限。
- 已有未结束任务阻止初始化；等待人工帮助的任务支持结束后重试。安装应在空闲时进行，初始化期间不要新建任务。
- 单元/模型配置变化才重启；候选激活失败恢复旧单元、配置和 AppArmor 策略。OpenHands 可选用量字段补丁受源码匹配约束，失败恢复原文件。
- 实际浏览器按钮验证初始化后自动连接任务服务与可视桌面；重复初始化六个服务 PID 和令牌摘要不变，既有任务记录保留。
- 限制：Ubuntu 24.04 x86_64；单用户可信环境。安装进度在本地内存中，重启本地服务后需重新检查。不是对全部发行版的承诺，也不迁移已有任务。
