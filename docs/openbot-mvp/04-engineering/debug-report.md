## 2. 已知风险（预检）

| 项 | 层级 | 症状 | 处理 |
|----|------|------|------|
| `IdentitiesOnly=yes` 在未指定 identity 时 | SSH | ssh-agent 密钥被忽略 | 仅当配置了 identityFile 才打开 |
| 无 TTY 的危险命令 | CLI | CI 里误跑 | 无 TTY 直接拒绝危险命令 |
| 隧道“假就绪” | 控制面 | 600ms 后 ssh 仍在但转发失败 | `/health` 轮询；失败要求重新 bind |
