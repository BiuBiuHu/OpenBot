# OpenBot 与 OpenHands 的 A2A 适配

这是已经说定的方案存档。写的是边界和做法。它不是完成声明，也不是用户页面上的验证记录。

## 当前事实

写这篇时，仓库里已经有这些，还没有按本方案改完：

- 一条对话。`runThreadTurn` 把用户原文交给 Pi 的 `createAgentSession`，不再用规则抢答。
- 时钟、读公开文档、网页查询是这个 Pi 会话上的工具。
- 远端是一个写死的 `ask_remote_agent`。它先看 `/.well-known/agent-card.json`。没有这张卡时，走现有 OpenHands `POST /api/conversations`，结果记成 `openhands`，不记成 `a2a`。
- 现在这份 OpenHands 不会发 agent card。上游没改。没有部署，没有 SSH。
- 连不上时活路径只回「连不上这台电脑。」活路径不在 60 秒放弃。

## 一个对话

用户原话先到本地 Pi。一个对话只发给拥有它的代理。没有确认交接卡，没有 This computer / Run on host。

Pi 只做两件事。

1. 基础聊天自己回。口气像人，一两句，像聊天。不列步骤，不复述工具原文。对方没问的不展开。
2. 对得上远端能力的，交给 OpenHands。做完用一两句告诉结果。

远端长结果留下，不原样贴进聊天。

## 能力从 agent card 来

能力清单从 A2A agent card 的 `skills` 读。不在 Pi 里写死跑命令、改文件、浏览器。

会话看到卡之后，把每条 skill 注册成 Pi 的一个工具。工具不自己做：不在本进程跑命令，不在本进程改文件，不用本进程打开那台电脑的浏览器。它只发 A2A 任务，等到终态再回来。

时钟、公开网页这种小能力留在 Pi，不放进这张卡。

没有合法 agent card 时，不注册这些远端工具，不发 A2A，也不把别的通道说成已经走了 A2A。

## 适配层

现在这份 OpenHands 不会发 agent card。适配加在我们部署的这份前面，不改上游。

适配层做三件事：

- 发出 `/.well-known/agent-card.json`。卡里的能力至少包括：在那台电脑上跑命令、改文件、用那台电脑上的浏览器。
- 按收到的 A2A 任务，转给这份 OpenHands 已有的对话接口去执行。适配层自己不充当那台电脑。
- 等到终态，把结果交回。不在 60 秒放弃。

官方以后自己会发卡，这层可以拿掉。

适配层的源码放在 OpenBot 仓库，供以后部署到我们自己的那份 OpenHands 前面。这次不部署，不 SSH，不改那台电脑上的文件。没部署之前，现网对端仍然没有卡，调用不得记成 A2A。

## 失败

连不上只回「连不上这台电脑。」任务没结束就继续等到终态，不回「这台电脑这轮没在时限里跑完。你再说一次就行。」

## 改文件

用户说了改哪个文件、写什么，并且当时的 agent card 里有对应能力时：Pi 把原话交给 OpenHands，做完用一两句告诉结果。长输出留下，不贴进回复。

## 不做

不部署。不 SSH。不改用户机器上的文件。不把密钥、PEM 或公网 IP 写进仓库。不合并。
