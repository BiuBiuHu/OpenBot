## 适配层放在哪

适配层源码写在 OpenBot 仓库，不改 OpenHands 上游：

- `src/a2a-adapter/card.ts`：agent card。上面有跑命令、改文件、这台电脑上的浏览器、读公开文档、网页查询。Pi 不把后两项留在本地。
- `src/a2a-adapter/server.ts`：发出这张卡，把任务转给现有对话接口，等到终态。
- `src/remote-agent.ts` 的 `loadRemoteSkills` / `sendA2aSkill`：Pi 只消费卡上的技能，没有卡就不发 A2A。

它是给以后放到我们自己部署的那份 OpenHands 前面用的。这次没有部署，所以现网那份 OpenHands 仍然不会发 agent card。没有卡时，调用不会被记成 A2A。只能等以后部署时把仓库里的这一层放上去。官方自己发卡之后，这层可以拿掉。
