# 用例清单

这些用例覆盖本地 Pi、远端 OpenHands、A2A 适配、口气、连接失败和能力清单。每条都能跑。模型是假的流，远端是 `127.0.0.1` 上的假服务。不访问公网，也不代表用户正在看的页面已经验证过。

读公开文档和网页查询是 agent card 上的远端技能。Pi 自己只留时钟。没有卡时，这两项也不会改成 Pi 的本地工具。

对应测试：

- `tests/a2a-adapter.test.ts`：TC-A2A-001 到 TC-A2A-003
- `tests/a2a-adapter-cases.test.ts`：TC-A2A-004 到 TC-A2A-023

| 测试名 | 人话 | 期望 |
| --- | --- | --- |
| TC-A2A-001 | 在吗 | 原话先到 Pi。聊天只回「在。」。模型若带上步骤清单，清单被拿掉。不叫远端，不发 A2A，也不留下长结果。 |
| TC-A2A-002 | 把 README.md 改成一行：你好；接着「跑一下 uname」 | 两句都先到 Pi。有卡时分别发成 `edit_file`、`run_command` 的 A2A 任务，OpenHands 收到原话。聊天是「改好了。写进那个文件了。」和「跑完了。」。长输出留在 `kept`，不贴进聊天。本机 README 不被改。不注册 `ask_remote_agent`。 |
| TC-A2A-003 | 把 README.md 改成一行：你好（对端没有 agent card） | 技能列表是空的，不注册 `edit_file`。不发 A2A，也不创建 OpenHands 对话。回复是「这会儿没有远端能力，我这边改不了那个文件。」不会被说成已经走了 A2A。 |
| TC-A2A-004 | 现在几点 | 原话先到 Pi，再调本地时钟。回复里有「现在是」和「上海」。不查网页，不发 A2A，不创建远端对话，不列步骤。 |
| TC-A2A-005 | 你是谁 | 原话先到 Pi。模型若回 OpenHands 介绍并列出步骤，聊天改成短的 OpenBot 自我介绍。不出现「我是 OpenHands」、工作目录或步骤。不叫远端。 |
| TC-A2A-006 | Grok Bot 是什么 | 卡上有 `web_search`，Pi 把原话放进 goal 发成 A2A。不在本进程查网页。提示里能看到卡上的这项能力，不说网页查询是自己的小工具。聊天是「Grok Bot 是 xAI 的对话机器人。」不贴「网上查过了」或长过程。长过程留在 `kept`。 |
| TC-A2A-007 | 看看 https://github.com/bojieli/ai-agent-book/blob/main/book/chapter3.md 这个文档讲了什么? | 卡上有 `read_public_document`，整句原话（含这个链接）发成 A2A。不在本进程抓页面，不改走 `web_search` 或 `edit_file`。提示不要求把公开文档留在本地。聊天是「我看过了。这一章讲用户记忆。」不访问 GitHub。 |
| TC-A2A-008 | 用那台电脑上的浏览器打开 https://example.com/docs | 卡上有 `browse_on_computer` 才注册这个工具。Pi 把原话发成 A2A，不自己打开页面。OpenHands 收到这个网址。聊天是「打开了。页面在那台电脑上。」长过程留在 `kept`。没有 `ask_remote_agent`。 |
| TC-A2A-009 | 谢谢，顺便把 README.md 改成一行：你好。 | 原话先到 Pi，再整句交给 `edit_file`。聊天只留「改好了。就改了这一处。」步骤和长过程不出现。长过程留在 `kept`。 |
| TC-A2A-010 | 跑一下 uname（远端要多轮才结束） | 等到终态再回「跑完了。」。通道是 `a2a`，任务已经发出。不出现「这台电脑这轮没在时限里跑完。你再说一次就行。」 |
| TC-A2A-011 | 把 README.md 改成一行：你好（适配层在，后面的电脑连不上） | 任务记成 `edit_file`。工具回给模型的只有「连不上这台电脑。」聊天也只有这一句。任务已发出，并且失败。不出现时限那句。 |
| TC-A2A-012 | 把 README.md 改成一行：你好（A2A 地址连不上） | 聊天只有「连不上这台电脑。」通道记成 `none`，没有发出，不记成 `a2a`。 |
| TC-A2A-013 | 跑一下 uname（远端留下一长段过程） | 成功时模型看到的工具结果是短句，没有这段过程。模型若把过程贴进回复，聊天只剩「跑完了。」过程留在 `kept`。 |
| TC-A2A-014 | 跑一下 uname（卡上只有改文件，另外两条技能 id 不合法） | 只注册 `edit_file`。`run_command`、`browse_on_computer`、`read_public_document`、`web_search`、`ask_remote_agent` 和非法 id 都不注册。提示里能看到这张卡自己的改文件说明，看不到没列上的能力。回复「这张卡上没有跑命令。」不发远端。时钟仍在。 |
| TC-A2A-015 | 没有单独的用户句子。读完整适配卡后看工具名单。 | 技能是 `browse_on_computer`、`edit_file`、`read_public_document`、`run_command`、`web_search`。这五项都注册。不注册 `ask_remote_agent`。 |
| TC-A2A-016 | 改代码 | 有卡也不发任务。原话先到 Pi。聊天是「说一下改哪个文件。」不列步骤，不提 OpenHands。 |
| TC-A2A-017 | 现在几点（本地模型没有密钥） | 仍走 Pi，不查网页，不按规则报时间。聊天是「本地模型还没配密钥。」 |
| TC-A2A-018 | 没有用户句子。卡缺技能列表、缺名字、技能 id 不合法，以及地址连不上。 | `loadRemoteSkills` 都得到空列表，不假装有远端能力。 |
| TC-A2A-019 | 没有用户句子。直接读适配层发出的卡。 | 名字是 OpenHands，协议是 HTTP+JSON。技能是跑命令、改文件、用那台电脑上的浏览器、读公开文档、网页查询。`loadRemoteSkills` 读到同一份。 |
| TC-A2A-020 | 把 README.md 改成一行：你好（远端以错误结束，并留下长日志） | 通道是 `a2a`，并且失败。回给模型的工具结果里没有长日志。聊天是「这台电脑这轮没做成。你换一句再试。」长日志留在 `kept`。不出现时限那句。 |
| TC-A2A-021 | 跑一下 uname（没有 agent card，走原来的对话通道） | 等到终态。通道记成 `openhands`，不是 `a2a`，也没有 A2A 发出标记。不出现时限那句。 |
| TC-A2A-022 | 没有用户句子。没有卡时看工具名单。 | 只有时钟。提示说时钟是自己的小工具，不出现 `read_public_document` 或 `web_search`。`edit_file`、`run_command`、`browse_on_computer`、`ask_remote_agent` 也不在。技能键是空的。 |
| TC-A2A-023 | 只含空白的句子 | 在任何远端调用之前拒绝，错误里有 `message required`。不创建对话。 |
