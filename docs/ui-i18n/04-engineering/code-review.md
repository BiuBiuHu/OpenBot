# 自审

- 共享 ES module + 双语词典，无 CDN、模型调用或新的第三方包。静态资源路径使用显式白名单。
- 仅标记的静态文案、属性与明确的动态 UI 文案参与翻译。没有遍历用户内容的自动替换器；目标、模型结果、文件、网站、原始字段 label/reason 保持原文。
- UI 偏好使用独立 localStorage 键；支持存储不可用时的内存回退、浏览器语言变化、同源标签页同步。不会保存表单值或远端凭据。
- 切换只更新文本与可访问性属性，不重新加载页面、重建私密表单或提交任务。已有加密链路未改变，相关测试通过。
- 动态绑定按节点更新并清理已卸载节点，避免轮询任务持续积累回调。真实任务结果到达时清除运行占位文案绑定，避免随后语言切换覆盖模型结果。
- 修复连接测试状态的旧绑定覆盖问题；扩展设置弹层滚动以适应英文长度。中英文移动端未出现横向溢出。
- 既有本机回复语言保留，明确与 UI 语言独立；不声称远端网页或模型输出会自动翻译。
- 回滚范围是本地静态 UI 与资源路由，没有远端服务、账户或数据库迁移。
