# 界面国际化实施计划

2026-11-21；用户授权实施。保存点 66af3a1，已同步 main，新分支 codex/ui-i18n。

范围：独立 OpenBot 主页、设置、任务状态、私密输入、测试入口和桌面查看器。界面语言与已有模型回复语言分开；首次采用浏览器首选语言（zh 系列→简体中文，其余→英文），手动 en/zh-CN 或 auto 保存在本地。切换不刷新页面、不提交任务、不改变输入值或远端状态。

选型：查阅 https://www.i18next.com/overview/api 和 https://github.com/i18next/i18next-browser-languageDetector 。当前为无打包的原生 HTML/ES modules、仅两种语言；采用独立本地词典与显式文本绑定，不引入 CDN、模型翻译或整页内容扫描翻译。按需扩展到 i18next，不改服务 API。

实现：共享语言模块和词典；静态文本/可访问性属性显式标记；动态 UI 文案通过翻译函数和可更新绑定渲染。任务正文、文件内容、网站内容、账号密码保持原文。语言切换更新 lang 和本地 UI；不等同翻译远端模型输出。

验证：语言检测、持久化、fallback、词典覆盖、受保护内容不变；构建和受影响回归；隔离浏览器验证中英文、刷新、未发送草稿与私密输入保留、移动端布局。回滚仅恢复 UI 与静态资源路由，无远端迁移。
