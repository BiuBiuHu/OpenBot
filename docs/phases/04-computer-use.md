# 阶段 4 · 电脑使用

独立文档。评审应能只读这一份就否定它。本阶段要验收的是「人看着 ECS 桌面、Agent 用这台电脑、人能接管」；**不是**把已经落地的 16:10 卡片再描述一遍就标绿。

卡片本身的约束已经是产品决策，本阶段不得拆掉。本阶段的 Agent 操作桌面能力**尚未**按下面评测验收。未验收却标绿，本阶段作废。

本阶段开始前，阶段 1、2、3 的评测必须全绿。其中任一阶段有一条红，本阶段不得绿。

## 目标

人在同一条聊天里让 Agent **使用 ECS 桌面**（打开程序、点页面、在人看得见的屏幕上做事）。人同时在笔记本页右边的电脑卡片里**看见**同一块帧缓冲，并随时**接管**（键鼠打到那块桌面）。

中间层仍只分发聊天句子。它不把「帮我打开浏览器」先分类成搜索然后自己打开笔记本浏览器。

## 非目标

- 不把 VNC 打到公网。
- 不把 noVNC 官方工具条当作产品 UI。
- 不做笔记本本机的 computer-use（操作的不是眼前这块笔记本桌面）。
- 不在本阶段发明第二条「桌面聊天」。
- 不把阶段 3 的文稿能力改成「必须在桌面编辑器里打字才算数」（桌面上改也可以，及格线仍是阶段 3 的工作区文稿 + 本阶段的可见屏幕）。
- 不合并 PR #7。

## 当前事实

评审请打开文件核对。

1. 电脑卡片在 `src/ui/index.html`：`.desk-wrap` 为 `aspect-ratio: 1280 / 800`，`border-radius: 0`，`clip-path: inset(0)`。按钮是「放大 / 收起」，不是「工具条」。
2. 放大：`.desk-wrap.max` 铺满窗口；双击卡片或 iframe 发 `openbot-desk-toggle`；`收起` 或 Escape（iframe 内 `openbot-desk-close`）回到小卡。
3. 观看器是 `src/ui/desktop-view.html`：只 `import` `/novnc/core/rfb.js`（或 `/novnc/lib/rfb.js`），只往 `#screen` 画布连 `ws://127.0.0.1:<localPort>/websockify`。不嵌入 `vnc.html` 的 chrome。
4. `src/desktop.ts` 把 `/novnc/` 代理到本机桌面端口（默认 6080）。HTML 即使没有 `Content-Type: text/html` 也会注入并拆掉 `#noVNC_control_bar` 等节点。探测成功时 `viewerUrl` 是 `/desktop-view`，不是公网 VNC。
5. 单测在 `tests/desktop.test.ts`（`TC-DESK-001`…`008`）：16:10、无工具条文案、注入、无 Content-Type 也注入、脚本不当 HTML。
6. **聊天不会驱动桌面。** 人说「打开浏览器」若阶段 1 已完成，句子会到 OpenHands；OpenHands 默认是工作区/终端，不等于「人在卡片里看见窗口被点开」。把卡片已能显示桌面当成「电脑使用已交付」，是否定本节目标。
7. 三台机器：卡片是笔记本页上的观看器；桌面进程在 ECS；noVNC 静态文件经环回隧道过来，不是第三台产品电脑。
8. PR #7 是叠在 PR #6 上的草稿，含上述卡片行为。保持草稿。

## 设计

1. **先重跑阶段 1 + 2 + 3。** 聊天抢答、改代码、文档评测任一条红，本阶段红。
2. **同一条聊天下指令，同一张卡片监视。** Agent 用 ECS 桌面时，帧缓冲就是卡片里那一块。人双击放大是为了看清和接管，不是新 mode。
3. **接管。** 键鼠打进 RFB 画布即接管。不经过 noVNC 侧栏。收起后仍是 16:10 小卡，仍可继续看。
4. **VNC 只环回。** `127.0.0.1:6080` 本地转发。文档和评测只写环回与「主机上的桌面端口」，不写公网 IP。
5. **中间层不替人开笔记本浏览器。** 「打开百度」是 ECS 桌面上的事。本机搜索短路一旦在阶段 1 之后回流，本阶段作废。
6. **语言。** 聊天回复仍用 Settings 语言。桌面里的应用 UI 随 ECS，不要求翻译像素。

评审若认为 computer-use 必须是截图工具循环而不是「人可见的 VNC 桌面」，请否定第 2 条。

## 现场页怎么验收

1. 重做阶段 1、2、3 的现场步骤。任一步失败，本阶段失败。
2. 看右边卡片：16:10，四角是矩形，没有 noVNC 标志和左侧按钮条，没有右侧黑弧。
3. 双击放大，画面铺满；点收起或 Escape 回小卡。再双击仍可放大。
4. 在聊天里请 Agent 在**桌面**上做一件看得见的事。卡片里应出现对应窗口，而不是只在聊天里报成功。
5. 人在放大后的卡片上自己点一下（接管），聊天不必因此切 mode。
6. 本机只出现环回地址。不要把桌面端口映射到 `0.0.0.0`。

## 什么情况本阶段作废

- 阶段 1 / 2 / 3 评测未重跑或有红却标绿。
- 把「卡片能连上 VNC」写成 computer-use 已交付。
- noVNC 工具条回到卡片；或再次用椭圆 / `border-radius: 50%` 裁桌面。
- VNC 对非环回开放，或文档写出公网 IP。
- 中间层把「打开某某网站」拦去本机搜索。
- 未先写 `TC-CU-VISIBLE-001` 这类会失败的测试。
- 合并 PR #7 或改打 `main`。
