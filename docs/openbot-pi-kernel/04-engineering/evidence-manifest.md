- 已通过：开场文案、在吗、你是谁、现在几点、改代码、点名改 README、`tests/pi-kernel.test.ts`、`TC-UI-001`。
- 未执行：有远端 agent card 的真机改文件、部署、SSH、全量 `npm test`。
- 阻塞项：页面截图被已打开的桌面画面卡住。适配层按方案不部署。
- 残余风险：时钟回复是模型转述，不是工具原文逐字。`TC-REMOTE-001` 在这台 Mac 上对 `uname` 期望 Linux，和这次改动无关，没有当通过。
