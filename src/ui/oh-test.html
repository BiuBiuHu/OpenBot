在你的笔记本上测 OpenHands 隧道。密钥只放 ~/.openbot/.env，本页不回显。 回会话台

1. 笔记本上先开隧道

Agent Server 只听主机 127.0.0.1:8000。另开一个终端：

ssh -i <SSH_IDENTITY> -L 8000:127.0.0.1:8000 <USER>@<ECS_HOST>

然后本机应能 curl -sS http://127.0.0.1:8000/health 看到 {"status":"ok"}。

~/.openbot/.env 至少：

OPENHANDS_BASE_URL=http://127.0.0.1:8000
OPENHANDS_API_KEY=<主机 OH_SESSION_API_KEYS_0>

可选：OPENHANDS_LLM_MODEL / OPENHANDS_LLM_API_KEY（远端循环自己的 BYOK）。不要把 PEM 或 key 贴进聊天。
