在你的笔记本上测 OpenHands 隧道。密钥只放 ~/.openbot/.env，本页不回显。 回会话台

1. 笔记本上先开隧道

Agent Server 只听主机 127.0.0.1:8000。另开一个终端：

ssh -L 127.0.0.1:8000:127.0.0.1:8000 user@host

然后本机应能 curl -sS http://127.0.0.1:8000/health 看到 {"status":"ok"}。

~/.openbot/.env 至少：

OH_BASE_URL=http://127.0.0.1:8000
OH_SESSION_API_KEY=<session-key-from-host-env>

也可写入 gitignore 的 .env / ~/.openbot/.env。远端模型用主机已配的 BYOK；不要把本机 OPENAI_MODEL 当远端。不要把 PEM 或 key 贴进聊天。
